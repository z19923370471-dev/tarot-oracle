# 星曜塔罗 · Tarot Oracle

一款把 **塔罗牌 × 星座星象 × 心理学** 结合起来的自我探索占卜网站。
它不把塔罗当“预测未来的水晶球”，而是当作一面**照见内心**的镜子——让你在抽牌、看星象、读心理映照的过程中，更清醒地察觉自己的状态与选择。

> 本项目为纯静态单页应用，无需构建、无需后端，浏览器直接打开即可使用。全部内容数据（**78 张塔罗牌**——22 张大阿卡纳 + 56 张小阿卡纳、12 星座、7 种牌阵、心理学框架）内置在 `js/data.js` 中。

---

## 快速使用

**方式一：直接打开**
双击 `index.html`，用任意现代浏览器（Chrome / Edge / Safari）打开即可。

**方式二：本地预览（推荐）**
```bash
cd tarot-oracle
npx serve .
# 或 python -m http.server 8080
```
打开 `http://localhost:8080`。

> 首页也内置了一个「预览示例解读」入口，无需填信息即可看到完整解读效果。

## 它如何把三者结合做“合理预测”

每次解读由**三重视角**合成：

1. **大阿卡纳本身**（22 张，均含正位/逆位）
   每张牌给出正位、逆位两种解读，以及对应的关键词，代表当下的能量状态与心理主题。

2. **星座星象共鸣**（需选择你的星座）
   - 每张牌对应一个星象（承接塔罗的 Golden Dawn 对应系统），例如 `恋人→双子座`、`死神→天蝎座`、`星星→水瓶座`。
   - **小阿卡纳使用 Golden Dawn 精确十进制星象**：数字牌(2–10)精确对应具体星座 + 十进制主星（如 `权杖·三→白羊座·太阳行`），命牌与宫廷牌对应所属元素的三星座。
   - 把**牌的对应星座/元素**与**你的星座元素**做匹配（同频 / 相生 / 需要磨合），生成一段专属的“星象共鸣”分析。
   - 四元素（火土风水）之间有明确的关系表，用于判定共鸣倾向。

3. **出生星盘 · 三大主星**（需填出生时间与地点）
   - 用天文算法（Meeus 近似）推算 **太阳、月亮、上升星座** 及三个主星上的 **元素分布**。
   - 其中 **上升星座** 由出生时间 + 经纬度决定，代表你展现给世界的一面（外层面具），是真正“个性化”的部分。
   - 解读的“星象共鸣”会把三大主星一并纳入，并以太阳为基底、上升为面向来共振。

4. **心理学映照**（荣格原型视角）
   - 用**荣格集体无意识原型**解释每张牌的心理意义。
   - 引入**投射机制**、**阴影自我**、**自知与能动性**等概念，把牌意转译为“自我觉察”的线索。
   - 刻意加入 **巴纳姆效应提醒**：占卜文本具有普遍适配性，容易被对号入座为“很准”，请把它当作镜子而非对命运的断言。

> 这样设计的目的：**“预测”的价值不在命中，而在帮你察觉现状、厘清选择、更自主地行动。**

## 功能清单

- ✦ **完整 78 张牌**：22 张大阿卡纳 + 56 张小阿卡纳（四套：权杖/圣杯/宝剑/星币，含宫廷牌），小阿卡纳自动补齐元素与星象对应
- ✦ **7 种牌阵**：单牌指引 / 过去·现在·未来 / 成长三牌 / 关系三牌 / 马蹄形七牌 / 凯尔特十字（10 张）/ 十二宫星盘（12 张）
- ✦ **6 个问题主题**：综合指引 / 爱情关系 / 事业学业 / 自我成长 / 抉择方向 / 近期运势
- ✦ **12 星座选择**（根据当前日期自动预选你的星座）
- ✦ **出生时间 · 三大主星星盘**：输入出生日期/时间/地点，结合天文算法推算出 **太阳、月亮、上升（Ascendant）星座** 与元素分布，并在解读中个性化引用
- ✦ **抽牌动画**：洗牌、翻转背面卡、按牌位翻牌；>5 张自动切换为带牌位标签的网格布局
- ✦ **完整解读页**：卡牌展示 + 星象共鸣 + 心理映照 + 行动建议 + 反思结语
- ✦ **本地历史记录**：每次占卜自动保存到浏览器 localStorage（上限 40 条），可随时回看历史解读、一键重开；支持清空
- ✦ **分享卡片**：canvas 生成解读分享图（PNG 下载）与一键复制解读文字；内置 **6 种主题**（星夜/晨曦/沧海/青玉/焰火/羊皮纸），可在解读页一键切换
- ✦ **响应式** 移动端适配、星空背景动画、神秘学暗紫鎏金视觉风格
- ✦ 示例解读深链 `index.html#example`，可直接分享/预览

## 项目结构

```
tarot-oracle/
├─ index.html          # 页面壳（欢迎/表单/牌阵/抽牌/解读 五屏 + 学习弹窗）
├─ css/
│  └─ style.css        # 主题与交互样式（暗紫 × 鎏金 × 星空）
├─ js/
│  ├─ data.js          # 内容层：78 张塔罗（22 大 + 56 小）/ 12 星座 / 四元素 / 心理学框架 / 7 牌阵 / 6 主题 / 出生地
│  ├─ astro.js         # 星盘计算：儒略日、太阳/月亮黄经、格林尼治恒星时、上升与中天、三大主星、元素分布
│  ├─ save.js          # 本地存储（localStorage 历史）+ 历史弹窗 + 分享卡片（canvas 出图）+ 复制文字
│  └─ app.js           # 逻辑层：导航、选择、洗牌抽牌（任意张数）、解读合成、三大主星接入、历史/分享、星空背景
└─ _test/
   └─ smoke.js         # 无浏览器 DOM 桩冒烟测试（控制台运行：node _test/smoke.js）
```

## 内容与合规说明

- 塔罗牌面以 **CSS 绘制的符号牌**呈现（序号 + 星象符号 + 关键词），避免使用受版权保护的具体塔罗牌画作。
- 本工具定位为**自我探索与心理觉察的辅助工具**，不构成医疗、法律或财务建议，也不可能预测真实未来。请理性使用。
- **星盘说明**：太阳/月亮/上升星座按 Meeus 天文公式近似计算，符号级精度足够判断星座；出生地目前仅支持**中国省级行政区**（以省会/首府坐标为近似基准，全中国 UTC+8、无夏令时），若出生时间临近星座交界，建议以专业星历软件复核。
